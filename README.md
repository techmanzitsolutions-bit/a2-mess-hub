# A2 MESS HUB V2

Premium room mess management app for Admin, Chef and Member roles.

## Features
- Admin / Chef / Member dashboards
- Member subscriptions and payment status
- Daily meals and meal counts
- Inventory and low-stock monitoring
- Expenses and chef salary overview
- Smart budget analytics and shopping suggestions
- WhatsApp message center UI
- Responsive dark emerald + gold mobile interface

## Android APK
GitHub Actions automatically builds an Android debug APK on every push to `main`.

Open **Actions → Build Android APK**. After the workflow succeeds, download the **A2-Mess-Hub-V2-APK** artifact. The ZIP contains `app-debug.apk`.

App ID: `com.a2messhub.app`
